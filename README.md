# Fastgrows assets

Private home for Fastgrows brand files, social posts and blog content.

| Folder | What goes there |
|---|---|
| `brand/logos/` | Logo files (black and white versions). Never recolour. |
| `brand/fonts/` | Atkinson Hyperlegible (social) and Archivo Black (blog). |
| `brand/brand-guide.md` | Colours, fonts, logo placement and post rules. Read this first. |
| `backgrounds/` | Realistic photos for post backgrounds. |
| `social/templates/` | Reusable layouts: single post, carousel, reel cover. |
| `social/YYYY-MM/` | Finished posts, one folder per month (e.g. `2026-11/`). |
| `blog/drafts/` | Blog posts not yet live, plus the publishing plan. |
| `blog/published/` | Move a draft here once it is live on the blog. |
| `blog/covers/` | 1200x630 cover images, named to match the post. |
| `clients/` | One folder per client. |
| `products/` | Things Fastgrows sells, like the salon Canva kit. |
| `docs/` | Notes and background context. |

Website and blog: https://www.fastgrows.com
